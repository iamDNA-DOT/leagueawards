# Unstop Igniters Club — The Legacy

A cinematic, static award-ceremony website built from the uploaded Igniters photos.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. In Vercel, import the GitHub repository.
4. Framework preset: Other / Static.
5. Build command: leave empty.
6. Output directory: leave empty.
7. Deploy.

## Edit content
Photo manifest: `assets/data.json`
Main page: `index.html`

## Notes
- The uploaded HEIC photo was not included because most browsers do not reliably display HEIC on websites. Convert it to JPG/PNG and place it under `assets/images/second-gen/` if you want it added.
- No personal names were invented because the uploaded folders did not provide names.
- The site is intentionally static: no backend or database is required.
